Big Question: Can the permanent of an m × m matrix be computed with a polynomial number of arithmetic operations?

The Core Dichotomy: VP vs VNP

Determinant (Easy) vs Permanent (Hard)

  • Determinant: Alternating signs allow cancellations → $O(m^3)$ Gaussian elimination → Class VP
  • Permanent: All positive signs → No cancellations → Requires summing $m!$ terms → Class VNP-Complete

Valiant's 1979 conjecture: VP ≠ VNP over any field.
